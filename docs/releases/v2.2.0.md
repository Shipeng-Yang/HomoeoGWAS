HomoeoGWAS v2.2.0 adds publication-ready output figures (`pip install homoeogwas==2.2.0`).

Added: `interact` now ends by writing a genome-wide interaction scan, an evidence
figure for up to 12 significant groups (or the top three when none is significant), a calibration figure and, for `smooth_pc4` runs,
a null-variance diagnostic, together with a `figures.html` page. `fit` draws the
subgenome PVE with bootstrap intervals, and `homoeogwas follow-up` draws
allele-combination means and accession-deletion robustness. `homoeogwas plot`
regenerates the figures of a finished `fit` or `interact` directory. Figures are
written as PDF, SVG and PNG; subgenomes are coloured by letter. The result JSON
records the bootstrap family minima, the per-edge component P values of reported
groups and the null-variance profile used by the figures.

No statistical code changed. Estimates, P values and decisions equal v2.1.4.
See the [changelog](https://github.com/Shipeng-Yang/HomoeoGWAS/blob/main/CHANGELOG.md) for details.
