HomoeoGWAS v2.1.4 is a patch release of v2.1.3 (`pip install homoeogwas==2.1.4`).

Fixed: the optional MCP interface is pinned to `mcp>=1.0,<2`. The 2.x series of
`mcp` renamed its server API, so a fresh `pip install "homoeogwas[mcp]"` could not
start `homoeogwas mcp`.

Changed: the documentation now shows the workflow figure, describes every input
and output file of `fit` and `interact`, adds an interaction quick start and the
full command list, and its algorithm page matches the current methods. Error
messages for the pairwise omniB compatibility wrapper and for
`scan.loco.fallback=emmax` are clearer. Species configs use relative example
paths, and tests that need local reference data are enabled through environment
variables. Internal development notes were removed from the repository and the
source distribution.

No statistical code changed. Estimates, P values and decisions equal v2.1.3.
See the [changelog](https://github.com/Shipeng-Yang/HomoeoGWAS/blob/main/CHANGELOG.md) for details.
